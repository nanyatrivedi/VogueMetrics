# VogueMetrics

AI-Powered E-Commerce Analytics Platform built using Python, SQL, Streamlit, Pandas, and Plotly.

## Features

* Executive KPI Dashboard
* Interactive State & Year Filters
* Revenue Trend Analysis
* Customer Segmentation
* Product Category Analytics
* SQL-Based Business Queries
* AI-Generated Business Insights
* Revenue Forecasting
* Top Performing Products Analytics

## Tech Stack

* Python
* Pandas
* SQL (SQLite)
* Streamlit
* Plotly
* Scikit-learn

## Analytics Features

### Executive Overview

* Revenue KPIs
* Order Metrics
* Customer Metrics
* Revenue Trends

### Customer Analytics

* Customer Segmentation
* High-Value Customer Analysis

### Product Analytics

* Top Product Categories
* Product Revenue Rankings
* SQL-Based Revenue Analysis

### Forecasting & AI

* Revenue Forecasting
* Automated Business Insights

## Business Impact

VogueMetrics helps businesses:

* Track revenue growth
* Identify top-performing regions
* Analyze customer behavior
* Forecast future revenue trends
* Discover high-performing product categories

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
